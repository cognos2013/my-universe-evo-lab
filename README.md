# 我的宇宙 · 演化实验室

一颗行星，两条历史。观察数字生命的生存、繁殖、变异与迁移，复制世界、改变条件，再比较不同的演化结果。

## 打开运行

需要 Node.js 24 或更新的兼容版本。

```bash
npm ci --ignore-scripts
npm run dev
```

浏览器打开 [本地模拟器](http://127.0.0.1:9150/)。所有模拟和存档在本机运行，没有外网部署。停止服务后重新执行 `npm run dev` 即可；请固定使用同一地址和端口，以恢复相同的浏览器本地存储。

## 第一轮体验

1. 点击“开始演化”，观察生命数量和资源变化。
2. 切换温度、生命、营养或谱系图层，点击星球表面查看区域。
3. 打开“干预与分支”，投入营养或施加限时热量；系统创建新时间线。
4. “开始对照”将两条时间线推进至同一时刻，再比较结果。
5. 点击“保存”，或“导出”完整实验文件；拖动“回到过去”滑块重放历史。

点击“← 宇宙总览”默认同步推进星球，每步一天；取消同步后可快速浏览亿年尺度的简化背景。宇宙年表为带来源的知识导览。哲学观察视角只改变解释，不改变自然规则。

最新进展：P10-A/B 的限定规模模拟已通过验收，76 项核心测试、14 项浏览器测试及引力动态审核通过。进入“宇宙总览 → 星系与恒星实验”观察运动与合并。旧天体存档可点击“从当前状态启用引力装配”。自动接续已开启，下一步 P10-C；[主线计划](docs/15-模拟能力主线-P10至P17.md)和 [P10-B 验收](docs/17-P10B-引力聚集与装配验收.md)持续记录未完成内容。

## 当前能力与边界

阶段证据见[进度与验收](docs/进度与验收.md)，最终状态以[自动审核报告](reports/final-audit.json)为准。

支持三个场景、320/1,280/5,120/20,480 网格、热量与模型物质收支、有限性状演化、随机重放、五种干预、分支对照、本地保存与完整导入导出。新建默认 5,120 区域，已有世界保留原精度，精度变化保持模板初始总物质不变。

本版尚未模拟大爆炸到人类的全程、前生命化学、多细胞身体、智能文明或真实地球未来。数字谱系不等于真实物种，单次分支差异不是现实概率。达到队列等计算预算时暂停并保留上一完整状态，不删除稀有谱系。

## 验证与命令行

```bash
npm run check          # 类型检查与核心测试
npm run test:browser   # 浏览器操作与响应性验收
npm run build          # 生产构建
npm run benchmark      # 标准规模与一万队列压力基准
npm run audit          # 全部审核，结果写入 reports/
npm run simulate -- two-lineages 100
npm run scenarios -- show two-lineages
```

浏览器测试优先使用本机 Google Chrome；没有 Chrome 时可执行 `npx playwright install chromium` 后运行。`npm run simulate` 默认为 320 单元的命令行生态模拟，最后一个可选参数为状态导出文件路径。时间线与实验完整存档请从界面导出。

## 队列达到上限时

“种群队列达到计算上限”表示该步没有提交。时间轴下方显示当前队列数和预算，点击“扩充计算容量”会从当前完整状态创建容量更大的分支，随后点击“开始演化”继续。每次翻倍，最低提升到 20,000，最高支持 100,000；原历史保留，内存消耗可能增加。扩容调整计算规则摘要，当前不能与原预算分支直接进行 A/B 对照。达到最终上限时请保存或导出实验。

旧世界仍为 1,280 区域时，点击时间轴下方“细分至 5,120 区域（新分支）”，无需重建生命；再次细分可到 20,480。
