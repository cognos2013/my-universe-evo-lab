# P1 环境与资源账验收

状态：通过。证据：[测试日志](../reports/P1-tests.txt)、[环境基准](../reports/P1-benchmark.json)。

## 成果

- 构建 320/1,280/5,120 单元的闭合二十面体细分网格，球面三角面积总和满足 4πr²。
- 稳定种子生成海陆分布，并明确海洋比例按单元数量近似；不是连续大陆生成器。
- 当地播种从营养池扣除结构物质；外部播种记录输入；初始能量包含明确的人工生命储备。
- 简化辐射热平衡、相邻单元守恒热交换、碎屑指数回收。
- 按稳定性估算子步，超预算/越界拒绝整个步；不污染原始状态。
- 命令行 `npm run simulate -- empty-planet 100` 推进环境并可导出状态。
- 存档升级为 schema 2.0.0 / engine 0.2.0 / interchange version 2，拒绝旧版本，防止遗漏新增能量账。

## 审核与验证

类型检查和 33 项测试通过。测试覆盖面积与邻接、初始物质、100 tick 守恒、非均温热交换、半步对照、失败原子性和序列化后续算一致。

首次非均温测试暴露 delta 写入覆盖邻居热量的问题，已修正为累加，并保留回归。热交换现在按边向两端写入相反通量。

## 关注事项

- 热模型不是天气模型；参数域仍需更广的收敛实验。
- 当前完整状态校验每步进行，可靠性优先；基准只测环境，不能推断生命阶段性能。
- 全球能量极大，个体储备的微小变化可能低于总账浮点精度；P2 还需单独检查局部生物能量分配。
- 拓扑由稳定算法生成，当前显示地形只是海陆分类，连贯大陆属于后续视觉与地理改进。
- P2 将接入生命，不把静态播种宣称为演化。
