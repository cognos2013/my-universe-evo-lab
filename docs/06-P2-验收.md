# P2 生命演化验收

状态：通过。证据：[42 项测试](../reports/P2-tests.txt)、[100 tick 基准](../reports/P2-benchmark.json)。

## 成果与审核

- 有限营养按需求分配，整数后代同时受能量和物质约束；小数名额随机分配，避免固定队列优先。
- 热适应与饥饿改变死亡率，死亡结构物质转回碎屑，维护和繁殖能量散入环境。
- 光能获取同时受细胞生理上限与本地已入射太阳能限制；从环境热量转入生物储备，保持总账。
- 宽耐受与高摄取增加维护成本；基因型无性遗传、非定向变异，父子谱系保留。
- 迁移使用邻接多项分配，数量和储备一起移动，移动成本回到热池。
- 生物覆盖按结构 MU 占比影响反照率，环境与生命已双向耦合。
- 输入顺序先规范化；同状态/种子恢复后结果一致。超队列预算原子拒绝，不删除稀有谱系。

## 测试覆盖

冷暖环境多种子选择、无资源/无能量无法繁殖、死亡回收、无突变无新性状、空星球、迁移守恒、随机分布均值、能量微小行星独立核对、40 tick 生态收支和100 tick命令行运行。

## 关注事项

- 数字生命不是真实物种；同父队列同一 tick 的突变后代共享一个新性状组合，以限制数量，不是每个突变个体独立基因组。
- 当前推进使用单个持久随机流，在确定排序下运行；独立事件流协议保留为后续优化。分支仍需多种子实验。
- 新生个体下一 tick 才迁移；队列没有年龄结构，模型卡应始终说明。
- 活跃队列默认上限 10,000；历史谱系上限 100,000。达到上限明确暂停，不声称无限开放演化。
- 首版反照率反馈以模型物质占比为代理，不是实测植被覆盖率。
- schema 3.0.0、engine 0.3.0、规则 2.0.0；旧状态因字段变化明确拒绝。
