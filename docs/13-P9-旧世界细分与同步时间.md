# P9 旧世界细分与同步时间

版本 0.9.0。处理用户反馈：已有世界仍显示 1,280 区域，以及宇宙播放时星球没有前进。

## 旧世界精度升级

原因为恢复了保存的 1,280 网格状态；修改新建默认值不会改变旧存档。现在时间轴下方提供“细分至 5,120 区域（新分支）”，再点一次可细分至 20,480。支持 320 → 1,280 → 5,120 → 20,480，每次四分。

细分从当前完整状态创建新分支，保留父历史、当前 tick、谱系及随机数状态。父格对应连续四个子格，面积、营养和碎屑按球面面积比例分配；余数留给末子格。温度和陆地比例继承，整数生命数量确定性分配，储备随数量分配。持续环境强迫映射到全部子格并保留截止时间。

这是一项明确的空间重建操作，不意味着从旧记录发现了真实地形细节。细分后迁移路径和局部资源条件发生变化，后续结果不保证与粗网格相同；不同精度分支拒绝直接同条件 A/B 对照。预算按实际需要调整，超过支持范围原子拒绝，父分支保留。

## 同步播放

宇宙总览默认勾选“同步推进星球（每步 1 日）”。每次等待 Worker 完成一个生态日后才更新宇宙经过时间，随后再请求下一步；不会堆积未完成请求。共同时间取自活动分支的整数 tick，刷新或切换分支后按当前状态重新读取。

宇宙背景参考年代为模型现今，经过时间为 `tick / 365.25 / 10^9` Gyr。面板同时显示星球第几日及宇宙经过几日。几十天内尺度因子变化极小，不能为了制造可见动画而把一天显示为十亿年。

暂停等待当前完整步结束；预算失败会停止同步，两者保留最后完成时刻。返回星球后可看到已推进的生态状态。取消同步后才开放跨亿年的背景滑块与快速动画，界面明确提示这不会计算对应的亿年生态历史。

这一步实现共享时钟和操作调度，没有添加星系、恒星演化或宇宙辐射对行星的物理反馈。宇宙早期到生命起源的连续多尺度计算仍未实现。

验收通过：65 项核心测试、13 项浏览器测试，以及类型检查、场景校验、构建和标准规模性能回归全部通过。

最终证据见 [自动审核](../reports/final-audit.json)。新增测试覆盖：1,280 世界推进后细分、人口/物质/能量守恒、逐父格资源总量、持续强迫映射、父历史不变、精细分支存档恢复，以及精度上限拒绝。

浏览器验证旧精度升级后仍保留日期与人口、刷新后精度正确；验证宇宙同步播放实际推进星球，双方显示相同完整日，暂停并返回后日期一致。沿用全部旧功能回归。

细分会增加内存和队列数量；仍可能触及计算容量。细分入口创建新分支，回看细分前的历史请切回父分支。用户应先保存或导出重要实验，再刷新应用加载新版本。
