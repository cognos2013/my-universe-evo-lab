# P10-B：引力聚集与星系装配

版本 0.10.1。交付为局部、孤立、软化引力沙盒，与 P10-A 气体及恒星群库存绑定；不是从宇宙密度扰动开始的完整结构形成计算。

## 已实现

每个气体晕具有三维物理位置（kpc）、速度（kpc/Myr）、引力质量（M☉）与内部角动量。新实验的初始晕位置来自种子，速度为零，暗物质质量为教学初值；动力学决定后续运动，未按年代解锁星系图标。

核心最多支持 64 个点状晕。使用成对对称力和 kick–drift–kick leapfrog 积分，默认子步 0.05 Myr，每个恒星群步 5 Myr 内推进 100 个引力子步。力采用 Plummer 软化：

```text
a_i = Σ_j G m_j (r_j − r_i) / (|r_j − r_i|² + ε²)^(3/2)
ε = 0.5 kpc
```

采用孤立开放边界与物理坐标，不使用周期边界，不叠加哈勃背景流。星系面板为 XY 投影，视野自动容纳天体，但显示实际范围、位置和速度；镜头范围变化不改变物理状态。

引力常数以 [NIST 所述的 G](https://www.nist.gov/how-do-you-measure-strength-gravity) 转换为 kpc³ / (M☉ Myr²)。积分与引力软化的方法背景参考 [Springel 2005：GADGET-2](https://wwwmpa.mpa-garching.mpg.de/gadget/gadget2-paper.pdf)。本实现是小规模直接求和器，没有移植 GADGET 代码或实现其 TreePM/SPH 功能。

## 装配与合并账

两个晕同时满足距离小于 1 kpc、相互接近和相对轨道能量为负，才采用简化非弹性合并。快速不受束缚飞掠不会只因距离近而合并。这一条件是可检查的模型近似，不能视为真实星系合并时间的校准预测。

合并以质量加权的位置和速度生成新装配体，保存两父 ID、子 ID、发生时间、质量与内部能量变化。轨道角动量转入子体内部自旋；合并前后未分辨的引力结合能与动能差进入有符号内部能量账，不无记录丢弃。该账并不等同于已经求解的气体温度、辐射或恒星反馈能量。

冷热气体、遗迹与初始重子质量相加。相同出生时刻、质量档的恒星群在当前模型下精确聚合，保留其出生时间；冷却时间按重子质量加权。引力质量包含重子与预置暗物质，当前恒星循环不改变总质量。

面板显示合并次数、完整父子记录、暗物质质量、物理坐标和总能量漂移。合并后自动选择仍存在的天体，避免选择已消费父体导致空面板。

## 存档与旧状态

天体子格式升级为 version 2，保存动力学、初始守恒量、内部能量和合并记录。完整实验仍为 version 2；生态状态格式不变。

旧天体 version 1 保留静态语义，不偷偷增加运动。面板提供“从当前状态启用引力装配”，按明确尺度解释旧位置、赋予零初始速度，并以当前时刻建立引力基线。这是新增模型条件，不能声称恢复了此前从未计算的运动史。

天体保存脏标记包含子格式版本与时间，确保在相同恒星 tick 启用引力后仍会保存。导入检查位置/速度、质量/动量、时间一致性、气体晕与动力天体对应关系及合并记录；无效输入不替换当前状态。

## 自动验收

状态：限定规模 P10-B 实现验收通过。76 项核心测试、14 项浏览器测试，类型检查、场景校验、构建、标准性能及引力动态审核均通过。默认 500 Myr 场景 8 晕形成 2 个装配体，最大相对能量误差约 2.99×10⁻⁴；原始数值见下方报告。

新增基准覆盖：

1. 自由粒子惯性运动；无效推进参数不修改输入。
2. 等质量圆轨道，对比软化圆轨道解析角速度，步长减半呈二阶误差下降；能量、动量及角动量误差受控。
3. 对称冷塌缩，天体相互接近且质心不漂移。
4. 受束缚合并前后的质量、动量、自旋加轨道角动量、总能量账；不受束缚飞掠不合并。
5. 输入存储顺序不影响结果；合并气体和恒星库存后可保存续算；旧格式显式启用引力。
6. 默认 8 晕场景推进 500 Myr 的动态回归，要求最大相对能量误差 < 10⁻³、相对动量误差 < 10⁻⁹、重子账绝对残差 < 10⁻³ M☉，且确实发生装配。

数值实测写入 [引力动态报告](../reports/P10B-dynamics.json)，全部任务结果见 [最终审核](../reports/final-audit.json)。浏览器检查真实天体状态、已合并后的选择、存档恢复及手机布局；截图见 [P10-B 面板](../reports/P10B-galaxies.png)。

## 关注事项

预置点状晕没有解析内部密度剖面，尚未从暗物质粒子或原初扰动生成晕；也没有流体、潮汐剥离、动力摩擦或吸积。合并采用有限尺度模型，并非已解析的真实碰撞。子步精度通过当前基准，不保证所有用户构造极端系统同样准确。

引力装配与气体冷却按分步算法衔接；恒星寿命与质量分布仍沿用 P10-A 教学参数。P10-C 需要继续校准这些参数并加入元素与反馈，整个 P10 不能因本子阶段通过就报完成。
