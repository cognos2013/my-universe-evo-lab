# P8 观察精度与宇宙总览

对应用户反馈：地表观察区域太少；界面只能观察一颗行星，缺少宇宙状态。交付包版本 0.8.0。

## 行星精度

新建默认从 1,280 提高到 5,120 个真实模拟区域，新增 20,480 区域选项，是原默认数量的 16 倍。网格、邻接、面积、环境场与区域点选均使用相同精度；不是单纯增加装饰三角形。相同模板的初始总物质和生命数量保持一致，但改变空间离散精度仍会改变局部条件和后续演化。

镜头可更靠近表面，光照采用球面法线，区域检查新增实际面积（km²）。以当前模板半径计，20,480 区域仍是平均约 2.5 万 km² 的区域尺度，尚非城市、个体生物或真实地形精度。

已有存档按原网格恢复；不自动细分或重置用户世界。体验新精度：先保存或导出重要实验，再选择“新建世界 → 观察精度 → 20480 区域”。旧模型和存档仍可加载；超精细场景独立提高 maxCells 并产生自己的规则摘要，不修改旧规则。

## 宇宙总览

行星上方增加“← 宇宙总览”。总览可拖动旋转、滚轮缩放，并在 1 亿年至 300 亿年间拖动年代或自动推进。显示尺度因子、膨胀率、相对现今物质密度及物质/暗能量占比。“进入当前生命星球”返回生态实验。

核心采用平坦、无压物质与宇宙常数的 FLRW 背景解析解：

```text
H(a) = H0 × sqrt(Ωm / a³ + ΩΛ)
a(t) = (Ωm / ΩΛ)^(1/3) × sinh(3 H0 sqrt(ΩΛ) t / 2)^(2/3)
ρm(t) / ρm(now) = a⁻³
```

H0 = 67.4 km/s/Mpc，Ωm = 0.315，ΩΛ = 1 − Ωm；单位转换到 Gyr 后计算。参数依据 [Planck 2018 VI](https://www.aanda.org/articles/aa/abs/2020/09/aa33910-18/aa33910-18.html)，膨胀背景参考 [UCLA 宇宙学教程](https://www.astro.ucla.edu/~wright/cosmo_03.htm)。这组模型依赖参数作为版本化参考值使用，不宣称为所有观测共同确定的唯一结果。

光点为有限共动采样盒中的示踪点，物理位置随 a(t) 缩放。采样盒边界不是宇宙边界；光点不是实际星系。没有重力聚集、星系或恒星形成，也没有光锥观测、辐射、曲率和早期宇宙模型。未来为参数固定下的外推，不能据此预测地球文明。

宇宙总览与生态时钟明确分开，打开时暂停生态模拟，改变年代不改变生态状态或随机数。总览年代目前为会话内观察设置，不写入生态存档；刷新后回到模型现今。当前生命星球尚无实际天文坐标或恒星系统耦合。
