## 现在可以体验

打开 [本地模拟器](http://127.0.0.1:9150/)。应用需要本地服务，不能直接双击 `index.html`。若服务已停止，在项目目录运行 `npm run dev`，然后访问同一地址。

1. 点击“开始演化”，观察生命、资源、温度和谱系的变化。
2. 旋转星球，切换图层，点击区域检查局部状态。
3. 打开“干预与分支”，投入营养或施加限时热量，生成另一条历史。
4. 运行分支对照，在同一模型日比较两条历史。
5. 保存并导出实验文件；用“回到过去”重放已计算的历史。

## 下一步需要关注

当前可运行的是简化行星生态模型。大爆炸到人类的连续模拟、生命自主起源、多细胞、智能文明与真实地球未来尚未实现。导览中的历史年代不会加载成对应的真实世界。

长期运行可能触及队列、分支和存档预算；系统会明确停止，保留完整状态。建议重要实验导出备份。完整浏览器/GPU 内存、跨浏览器重放及现实数据校准尚未验证。

后续优先补齐长期实验的历史压缩和预算管理、模型校准与批量多种子实验，再逐层加入恒星边界、复杂生命和文明机制；不以时间阈值直接生成智慧生物。
