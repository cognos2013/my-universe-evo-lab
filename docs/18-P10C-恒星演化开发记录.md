## 质量分布基础

新增 `src/simulation/cosmos/imf.ts`，按 [Kroupa 2001 v2，式 2](https://arxiv.org/html/astro-ph/0009005v2) 实现银河场星初始质量函数的连续分段积分。0.08—0.5 M☉ 采用斜率 1.3，0.5—100 M☉ 采用 2.3；后段连续系数为 0.5。100 M☉ 上限为本实验截断选择，排除褐矮星；这不是已验证的原初恒星质量分布。

输出每个质量区间的质量占比、每单位出生质量的期望数量和数目加权平均质量。群体数量为连续期望量，不能当作逐颗恒星或小星团随机采样结果。解析积分使用稳定的指数差写法；要求区间完整覆盖、严格递增且有限。

以 0.08、0.5、8、100 M☉ 分界，计算质量占比分别约为 0.280132、0.510731、0.209137。质量份额不等于数量份额，寿命不能直接用同一平均质量替代整段积分而不做收敛验证。

新增三项测试：归一化与分箱细化可加性、独立对数网格数值积分对照、无效边界拒绝。`npm run check` 通过：79 项核心测试及类型检查；日志为 [P10-C 基础检查](../reports/P10C-imf-check.txt)。尚未接入主模拟和 UI，因此本次没有重复浏览器测试；上一轮 B 全量报告仍对应 B 的源码版本，不作为新增模块的全量验收。

## 后续实施顺序

1. 固定恒星轨道资料版本与适用金属丰度。[MIST 官方模型页](https://mist.science/model_grids.html) 已核实提供 EEP 轨道；候选 v1.2 非旋转太阳金属丰度包约 96 MB。还未下载、提取或校准。需保存来源、文件校验值、字段单位及演化终点含义，不能将轨道最后一行一概称为恒星死亡。
2. 选择可追溯的恒星风、元素产额与残骸资料，核对净产额和总抛射量的区别。总金属只是重子质量的一部分，生成新元素必须消耗原有成分；零产额控制实验不产生新增金属，原初氢氦经明确核合成可产生金属，不可误解为必须有初始金属才允许核合成。
3. 为每批恒星保留出生金属丰度、质量分箱和来源版本，加入按事件时刻分段的返还、热反馈和残骸账。先通过单批恒星质量/成分/能量账以及分箱、步长收敛，再接通气体晕。
4. 扩展存档版本并显式处理旧教学恒星群：不能把已出生群的年龄与剩余寿命静默改写成新规则。补齐面板来源、单位、边界和迁移测试，最后执行全量审核。

## 关注事项

现有气体初始状态没有金属丰度字段；太阳金属丰度轨道和银河场星 IMF 不能直接证明第一代原初恒星演化。需明确区分已富集模板实验与原初假设，或选取覆盖原初条件的数据后再接入。当前线上界面仍使用 P10-A 的教学恒星参数，独立 IMF 模块不意味着寿命、元素、反馈已完成。
