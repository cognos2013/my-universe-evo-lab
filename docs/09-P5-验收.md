# P5 干预分支验收

状态：通过。52 项核心测试、5 个浏览器用例与生产构建通过。见 [核心日志](../reports/P5-tests.txt)、[构建日志](../reports/P5-build.txt)、[对照截图](../reports/P5-comparison.png)。

## 成果

营养补给、限时热量强迫、区域灾变、人工播种与性状修改均可操作。每次 UI 干预先复制当前状态到子分支；失败时删除此次未完成子分支并回到原分支。

命令 ID 与摘要保存为收据，重复执行返回原效果，不重复投入；同 ID 不同内容拒绝。持续强迫的起止时刻、区域和幅度随世界状态保存，过期自动移除效果，收据保留。

分支列表显示父来源与分叉时刻；两条时间线可推进至同一个绝对模型日，再比较人口、温度、营养和活跃谱系。实验导出包含全部分支、检查点、命令与样本。

## 审核

- 无干预兄弟分支自然演化结果一致；运行子分支不修改父状态。
- 营养投入与物质账一致，人工播种的储备能量显式记为外部输入。
- 修改性状只拆分相应队列，保留总数量与储备，标为人工谱系。
- 恰好两 tick 的强迫在第二步之后归零，中途保存不改变结果。
- 从灾变之前重新推进，与原来带灾变历史完全一致。
- 浏览器验证干预、对照、保存、刷新、切回父时间线的完整流程。

## 关注事项

单次对照可能因为随机路径变化而出现反直觉差异，不显示为现实概率或普遍结论。批量多种子分析属于后续增强。

当前最多 20 个分支、100,000 个历史谱系。初始空星球保留人工基因型模板供播种，但没有活体，不会自行生成生命。

当前存档使用 state schema 4.0.0 / engine 0.5.0，timeline version 2，experiment version 1。含干预的状态不能加载到旧引擎。
