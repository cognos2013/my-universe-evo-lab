# P10-A：气体冷却与恒星群演化

版本 0.10.0。P10-A 为星系与恒星主线的第一项可运行子模块；P10-B 引力装配和 P10-C 元素/恒星模型仍未完成。

## 入口与交付

打开“宇宙总览 → 星系与恒星实验”。初始为 8 个预置气体晕，不含恒星。可按 500 万年、1 亿年、5 亿年前进，点选每个晕查看冷热气体、恒星质量、遗迹、估算光度和形成批次。图中位置仅为实验示意坐标。

该深时间实验独立于生态分支，完整实验文件共享一份天体状态；它不会跳算星球亿年的生态历史。进入天体实验会停止宇宙同步播放。它与现有逐日同步模式不是同一个物理耦合功能。

## 机制与单位

- 起始宇宙年龄 100 Myr，每步 5 Myr；初值和冷却参数由固定种子生成。
- 每个晕的热气体按 `1 − exp(−dt / coolingTime)` 转入冷气体。
- 冷气体按 `1 − exp(−dt / 2000 Myr)` 分配给新形成的恒星群，消耗等量气体。
- 新生质量按 0.5 / 0.3 / 0.2 分给三个代表质量档；这是教学参数，不是已校准初始质量函数。每组可代表大量恒星，不是逐颗个体。
- 各档寿命分别为 100,000 / 1,000 / 20 Myr；到期后，质量按 0.4 / 0.7 / 0.85 返还热气体，其余进入遗迹池。返还气体可以再次冷却形成新恒星群。
- 代表恒星质量为 0.5 / 2 / 12 M☉，光度为 0.06 / 16 / 10,000 L☉，仅用于估算总光度，未驱动行星辐射。
- 近似质量账为热气体 + 冷气体 + 存活恒星质量 + 遗迹 = 初始气体质量；尚未追踪核反应质量亏损、暗物质或外部吸积。

冷却时间范围、耗气时标、质量档、寿命、光度和回流率均为项目设计值。NASA 的[恒星说明](https://science.nasa.gov/universe/stars/)支持“恒星形成于气体、演化并返还物质”的定性机制；[星系随时间变化](https://science.nasa.gov/mission/webb/galaxies-over-time/)说明星系包含气体、恒星和暗物质。这些资料不构成对本模型参数或结果的定量验证。

## 存档与故障

完整实验格式升级为 version 2，新增可为空的 astronomy 状态；旧 version 1 实验和兼容的单时间线继续可导入。天体状态改变时触发保存脏标记，避免生态 tick 不变导致遗漏天体进度。保存失败仍依照主界面实际状态提示，不能把“计算完成”等同“已保存”。

验证状态结构、版本、有限非负数、恒星群年龄、重复批次与每个晕的质量账，再校验完整文件摘要。每步复制并完成校验后才发布；最多 2,000 步，即从起点演化 100 亿年。长批次最多一次 100 步，可在完整步边界停止；不会静默削减恒星群。

## 验收

状态：P10-A 子阶段验收通过。69 项核心测试、14 项浏览器测试，以及类型检查、场景校验、构建和标准规模性能回归全部通过。P10 整体仍未完成。

自动测试覆盖：无气体不产生恒星或遗迹；形成必须消耗气体；高质量群按声明寿命死亡并回流；长运行质量账闭合；相同种子初值相同；保存续算一致；负库存、旧格式与时间预算边界正确处理。

浏览器覆盖：由零恒星推进至有恒星、查看气体晕、保存后刷新恢复天体年代、生态日不变，以及窄屏面板无横向溢出。最终以 [自动审核](../reports/final-audit.json)为准；截图见 [P10-A 面板](../reports/P10A-galaxies.png)。

## 明确未完成

没有计算暗物质聚集、引力塌缩、晕合并、空间气体动力学、恒星级轨道、金属核合成、恒星反馈风或恒星—行星辐射耦合。预置气体晕不能被称为从大爆炸自发形成的星系；有恒星的气体晕数量也不是宇宙星系总数。

本子阶段没有天体历史滑块、天体分支或天体干预；当前保存/恢复的是天体末态，确定性续算已测试。独立天体历史与跨尺度绑定须在后续合同中补齐。原始 5 Myr 步长会量化形成和死亡时刻，尚未进行完整步长收敛与观测校准，不能用于定量天体预测。
